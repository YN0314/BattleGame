# Geminiへの指示文（スプライト元絵の生成）

目的: 写真から作ったキャラ絵を基準に、骨格ガイドどおりのポーズ画像を Gemini（Nano Banana）で作る。
最初は4ポーズ（待機・パンチ・キック・被弾）で一貫性を試す。同じチャットの中で続ける。
ガイド画像は `docs/pose_guides/gemini/` にある（guide1_idle.png、guide2_punch.png、guide3_kick.png、guide4_hit.png）。

## 手順
1. 新しいチャットを開き、基準にするキャラ絵（と本人の写真）を添付して「指示文1」を送る。
2. 気に入る基準絵が出たら、同じチャットで骨格ガイドを1枚ずつ添付して「指示文2」を送る（ポーズ別の一文を差し替える）。
3. 出てきた画像を保存して、Claudeに渡す（背景除去、サイズ・足元位置の正規化、ゲームへの取り込みは Claude 側で行う）。

## 指示文1（基準絵）
添付の画像の男性を、2D格闘ゲームのキャラクターにします。まず基準になる絵を1枚作ってください。
- 同じ人物（顔立ち、眼鏡、髪型、体型）、同じ服装（白い長袖シャツ、濃紺のネクタイ、黒のスラックス、黒い革靴）にする
- 完全な横向き（右向き）の全身にする。構えは、軽く膝を曲げて両拳を顔の前に上げた格闘の待機姿勢
- 背景は、無地の純粋な緑（#00FF00）一色にする。影、地面、オーラ、炎、桜、建物、文字、枠は入れない
- 頭から靴の底まで、全身を切らずに入れる
- 画風は、添付の絵と同じ、輪郭線がはっきりしたゲーム用イラストにする
- 画像は正方形

## 指示文2（ポーズ別。ガイド画像を添付して送る）
添付の棒人形（骨格ガイド）のとおりのポーズで、さきほどの基準絵と同じ人物を描いてください。
さきほどの絵の姿勢や手足の位置は引き継がず、ポーズはガイドだけに従ってください。さきほどの絵から引き継ぐのは、顔立ち、眼鏡、髪、服装、約4.6頭身の体型、画風だけです。

ガイドの読み方:
- 黄色い丸＝頭。丸の中の黒い点がある側が顔の向き（右向き）
- 緑の線＝胴体、赤い線＝手前側の腕と脚、青い線＝奥側の腕と脚、白い点＝関節
- 赤と青の大きな丸＝手
- 灰色の横線＝地面（足の裏の高さ）

守ること:
- 頭、手、足の位置と体の傾きを、ガイドに合わせる。ガイドの線や丸は、絵に写さない
- 全身の大きさと位置もガイドと同じにする（黄色い丸の大きさ＝頭の大きさ）。足の裏は灰色の線の高さに合わせる
- 赤い側の手足が、絵の手前側に見えるようにする
- 人物、服装、画風は、基準絵と完全に同じにする
- 頭を大きくデフォルメして、約4.5頭身にする（ガイドの黄色い丸が頭の大きさ）
- 表情は、落ち着いた真剣な顔にする（怒りすぎない）
- 背景は、無地の純粋な緑（#00FF00）一色にする。影、地面の線、オーラ、エフェクト、文字は入れない
- 画像は、ガイドと同じ正方形にする

ポーズ別の一文（上の文章に足す）:
- 待機: 軽く膝を曲げ、両拳を顔の前に構えた待機姿勢。
- パンチ: 手前（赤）側の腕をまっすぐ前に突き出した、パンチの瞬間。もう一方の拳は顔の前に残す。
- キック: 奥側（青）の脚で立ち、手前（赤）側の脚を腰の高さで前に蹴り出した瞬間。蹴った足先はほぼ水平。
- 被弾: 殴られて上半身が少しのけぞった姿勢。顔は苦痛でしかめ、目をつぶる。腕は力なく下がり気味。

## うまくいかないとき
- ポーズがずれる: 「ガイドの○○の位置が違います。赤い手をもっと前に」のように、ずれた場所を具体的に指摘する。
- ポーズが前の絵のままになる: 新しいチャットで、基準絵とガイドだけを添付して始める。
- 服や顔が変わる: 「基準絵と同じ服装・同じ顔に戻してください」と言い、必要なら基準絵を再度添付する。
- 全身が切れる: 「全身を余白付きで入れてください」と頼む。
- Nano Banana 2 と Pro の両方で試し、似具合を比べる。

## 合格の目安
- 4枚とも同じ人物に見える（顔、眼鏡、髪、服）
- ポーズがガイドの位置と大きくずれない
- 全身が入り、背景が緑一色で、影やエフェクトがない
