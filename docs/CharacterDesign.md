# キャラクター絵 制作仕様書(スプライトシート)

このゲームのキャラクターを、手描き・画像生成などの「絵」で作るときの決まりごとです。
絵を受け取ったら、`tools/aseprite_to_sheet.py` で取り込み、ゲームに登録します(手順は `assets/README.md`)。

付属の `pose_guides/` に、全ポーズの**骨格図**(`skeleton/`)と**シルエット**(`silhouette/`)があります。
一覧は `contact_skeleton.png` / `contact_silhouette.png` を見てください。

---

## 1. 画像の基本ルール

| 項目 | 決まり |
| --- | --- |
| 向き | **右向き**(相手は常に右側。左向きはゲームが反転する) |
| 背景 | 透明(PNG、アルファあり) |
| 1コマの大きさ | 全コマ**同じ大きさ**の正方形(下表の3段階から1つ選ぶ。キャラごとに統一) |
| 足元の基準点 | 全コマ**同じ位置**に足元の中心を置く(下表の「足元」)。ポーズが変わっても基準点がずれないこと |
| 縁取り | 暗い色の輪郭線(1ドット)を推奨。背景と混ざらないこと |
| 光 | 左上から。陰影は2〜3階調 |
| 色数 | 1キャラ 40〜64色程度に抑える(ドット絵の質感を保つため) |
| 2P色 | 服の色を変えた別PNGを1枚(同じ配置)。無ければ1Pと同じ絵を使う |

### コマの大きさ(精細さ)

| 段階 | 1コマ | 足元(x, y) | 立ち姿の高さの目安 | `--art-scale` |
| --- | --- | --- | --- | --- |
| 標準 | 128×128 | (64, 116) | 約100ドット | 2 |
| 高精細 | 192×192 | (96, 174) | 約150ドット | 3 |
| 超高精細 | 256×256 | (128, 232) | 約200ドット | 4 |

- 見せていただいた takahashi の絵は、目安として「標準〜高精細」のあいだです。**先に1人だけ作って見え方を確かめてから**段階を決めるのがおすすめです。
- 段階を変えてもポーズの大きさの比率は同じです(足元の位置と立ち姿の高さを、表の割合でそろえる)。
- 技の腕・脚が伸びても切れないよう、コマの左右には余白をとってください(強パンチ・飛びキックは足元から右へ最大約 45 単位=標準で90ドット伸びます)。

## 2. 骨格図の見方

- 画像は 768×512。**1単位 = 8 ピクセル**。足元(黒い点)は左から 288、上から 464 の位置。
- 色:**赤=手前側の手足 / 青=奥側の手足 / 緑=胴 / 黄丸=頭**(点が目の位置=顔の向き)。
- 白い点=ひじ・ひざ・腰・胸。大きい色付きの点=こぶし。
- 骨格は「関節の目安」です。絵は骨格にぴったり合わせる必要はありませんが、次は守ってください。
  - **手足の届く位置と向き**(攻撃のあたり判定は骨格を基準にしている)
  - **頭の位置**(やられ判定の基準)
  - **足元の基準点**
- ジャンプ系ポーズ(`jump`、`jumpPunch` など)は、**足を地面の近くに描く**(空中の高さはゲームが動かす)。
- シルエットは体格の見本です(髪型や服は無視してください)。

## 3. 作るポーズの一覧

コマ番号は、攻撃では **0=構え(発生前) → 1=攻撃中(いちばん伸びたところ) → 2=戻り(硬直)** の順にゲームが進めます。

### 優先度1(まず最初に作る:これだけで戦える)

| ポーズ | コマ | 内容 |
| --- | --- | --- |
| `idle` | 4(最小2) | 待機(繰り返し) |
| `walk` | 6(最小4) | 歩き(繰り返し) |
| `jump` | 1 | ジャンプ |
| `crouch` | 1 | しゃがみ |
| `guard` / `crouchGuard` | 1+1 | 立ち/しゃがみガード |
| `standPunch` / `standKick` | 3+3 | 立ち弱パンチ/弱キック |
| `standHPunch` / `standHKick` | 3+3 | 立ち強パンチ/強キック(体ごと踏み込む大振り) |
| `hit` / `down` | 1+1 | やられ/ダウン |

(合計 約 28コマ)

### 優先度2(通常技を埋める)

`crouchPunch` `crouchKick` `jumpPunch` `jumpKick` `crouchHPunch` `crouchHKick` `jumpHPunch` `jumpHKick`(各3コマ)、`throw`(3)、`dizzy`(4、繰り返し)

(合計 約 36コマ)

### 優先度3(必殺技:キャラごとに使うものだけ)

| ポーズ | コマ | 内容 | 使うキャラ |
| --- | --- | --- | --- |
| `fireball` | 3 | 飛び道具(超必殺 `superfireball` も同じポーズ) | HERO / IMAI / KIRA / NAKANO / TAKAHASHI / MEI / ISA / JAX / PRIYA ほか |
| `uppercut` + `uppercutLand` | 3+1 | 昇龍 | HERO / IMAI / KIRA / NAKANO / BORIS / JAX |
| `flashkick` | 3 | サマーソルト | IMAI / KOSHIKA / TAKAHASHI / MEI / ISA / PRIYA / NAKAGAWA |
| `flyKick` | 3 | 飛びキック | KIRA / MEI |
| `spinKick` | 3 | 回転蹴り | KOSHIKA / ISA |
| `straight` | 3 | ストレート | NAKANO / JAX |
| `palmStrike` | 3 | 掌底(円盤を飛ばす技 `chakram` で使う) | KOSHIKA / TAKAHASHI / PRIYA |
| `tackle` | 3 | タックル | BORIS |
| `slam` | 4 | 叩きつけ | BORIS / PRIYA / NAKAGAWA |
| `paperToss` / `briefcase` / `overtime` | 3 | NAKAGAWA 専用 | NAKAGAWA |

※ 写真から作ったキャラ(IMAI など)の必殺技の割り当ては仮です。決まったら、その技のポーズだけ作ればよいです。
※ 絵が無いポーズは、自動生成の絵(`fallback`)で補われます。**少しずつ差し替えられます。**

## 4. 絵を作る流れ(例)

1. 写真から、そのキャラの**基準絵**(待機ポーズ・全身・右向き)を1枚作り、顔・髪・服・小物をここで確定する。
2. 骨格図(`skeleton/ポーズ名_コマ.png`)をポーズの指定として使い、基準絵の人物にそのポーズを取らせる。
3. 全コマを同じ大きさ・同じ足元位置にそろえる(Aseprite で、足元の基準点にガイドを置く)。
4. Aseprite で、**ポーズ名のタグ**(`idle`、`standPunch` など)を付け、各タグにそのポーズのコマを並べる。
5. File > Export Sprite Sheet で「JSON Data」と「Tags」を有効にして書き出し、PNG と JSON を渡す。
6. 取り込み: `python3 tools/aseprite_to_sheet.py 書き出したJSON 名前 --art-scale 2`(段階に合わせて 2/3/4)

### 点検リスト

- [ ] 右向きで、全コマ同じ大きさ・足元の位置が同じ
- [ ] 顔・髪・服・小物が全コマで同じ(特に眼鏡、ネクタイ、ストラップなどの小物)
- [ ] 手足の長さがコマごとに変わっていない(強攻撃でも極端に伸びない)
- [ ] 攻撃コマの手・足の先が骨格図の位置にある
- [ ] 背景が透明で、輪郭にゴミ(半透明の縁)が無い
- [ ] 2P色は同じ配置で、色だけ違う

## 6. 画像生成AIで元絵を作る場合
Gemini（Nano Banana）などで元絵を作る手順は `docs/Gemini指示文.md`、渡す骨格ガイド（待機・パンチ・キック・被弾）は `docs/pose_guides/gemini/`。基準絵は、この仕様書の頭身（約4.3頭身）に近い約4.5頭身で作る。取り込みは、スプライトシート（`assets/README.md`）の手順で行う。
